# claude-update: обновить Claude Code кнопкой

Плагин для [Agents Hub](https://github.com/flagman/agents-hub-core). Вкладка «Настройки» → «Claude Code» показывает,
какая версия Claude Code стоит, какая доступна и как claude поставлен на этой машине. Кнопка «Обновить» ставит новую
версию тем же способом:

- установщик Claude Code (`~/.local/share/claude/versions`): `claude update`;
- npm: `npm install -g @anthropic-ai/claude-code@<канал>` из той же папки, где стоит claude;
- Homebrew: `brew upgrade --cask claude-code`.

Потом плагин пишет хаб-сессии, чтобы она перезапустила хаб, когда сессии свободны (`hub restart`). Сам плагин весь
хаб перезапустить не может. Сессии работают на старой версии, пока хаб не перезапустится. Вкладка показывает, какие
сессии запущены раньше, чем поставлена нынешняя версия, и даёт кнопку «Перезапустить хаб».

Автоматики нет: обновление только по нажатию, с подтверждением.

Доступную версию плагин берёт из реестра npm, канал — `autoUpdatesChannel` из настроек Claude Code (`latest` по
умолчанию или `stable`). Claude — тот же, что запускает хаб: `HUB_CLAUDE` или первый `claude` в PATH.

Несколько хабов на одном Mac обычно делят один claude. Обновили из одного хаба — у другого вкладка покажет его сессии
на старой версии и кнопку «Перезапустить хаб».

## Установка

«Настройки» → «Плагины» → поставить из маркетплейса. Без маркетплейса — строкой в `hub.json`:

```json
"extensions": {"claude-update": {"path": "~/hub-plugin-claude-update", "web": "web/main.js", "run": ["python3", "main.py"]}}
```

У плагина есть процесс (`main.py`): он узнаёт версии и запускает обновление. Страница говорит с ним по HTTP на порту
страницы + 11 (у страницы на 8787 — 8798), только со своей страницы. Нужен API плагинов хаба 1.7 или новее.
